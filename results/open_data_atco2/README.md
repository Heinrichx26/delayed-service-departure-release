# ATCO2 metadata calibration

The repository includes the parser and saved summaries for the public ATCO2 XML metadata. The current archive contains 560 recordings and 877 timestamped speech segments from seven airports. The parser reports airport, channel, UTC timestamp, speaker role, segment start and end, and derived segment and turn-gap statistics. The audio archive is not redistributed. These metadata support calibration of radio transmission occupancy and timing; they do not identify the model-specific future-runway-service-count request.

Source: ATCO2 corpus paper and public data page (see the manuscript bibliography).
